# CedarView

Are you a student of Cedarville University? Do you wish there was an easier, faster way to view myCU info than going to the website and searching? Well now there is!!

CedarView is an app developed for **Android devices** to quickly display:
- Next Chapel speaker
- Your personal number of remaining Chapel skips
- Your FLEX dollar balance
- Your remaining meal scans
- What Homecooking is serving at next/current meal

So, how do you get it?

## Install

Unfortunatly, this app is currently not avaliable on Google Play. Instead, you will have to download it from this repo. To be transparent, the entire source code is open source and publically available.

### To install

Click on the most recent release to download the .apk file.

**Samsung**: Settings → Security and privacy → Auto Blocker → turn off. On One UI 6.1+ this is on by default and blocks the install outright with no "install anyway".<br>
▎ **All phones**: Chrome will warn on download → Keep. Tap the file, allow "install unknown apps" for your browser when asked. Play Protect will say unknown developer → More details → Install anyway.<br>
▎ Requires a 64-bit phone (any Pixel, or Samsung/Motorola from ~2019 on).
